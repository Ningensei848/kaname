# 収集・生成Note・公開の方針

LLMが生成したcompact Note群を公開する方針はユーザーが指定しました。
人力Vaultの内容と公開範囲は別リポジトリで管理し、kanameの入力・配布対象にしません。

## 取得と要約

現在のsourceはGoogle Research/GitHub Blogです。AWS Newsは利用条件に関する未解決の制約から無効を継続します。
source追加時は適用される条件と機械可読の指示を確認し、robots拒否・取得不能時は停止します。
robotsで取得可能であることだけを、要約・再配布に関する権利の根拠とみなしません。
CAPTCHA、認証、paywall回避は行いません。

LLMには変換後Markdownの先頭20,000文字までを送信します。
外部知識による補完を求めず、画像は取得できたalt等のテキストだけを根拠にします。
広告等の本文外要素はpromptで除外を求めますが、全件の日本語事実確認を自動保証しません。
NoteにはAI生成・入力打切り・生成情報と出典を表示します。

## 公開する成果物

生成要約、重要ポイント、検索語、資料の位置づけ、出典を持つ成功Noteを共通Git snapshotにします。
記事原文の再掲、raw HTML、外部画像の転載、認証情報、復旧/課金台帳は含めません。
2026-10-10のユーザー確認により、新規Noteは本文に関係する画像を出典のHTTPS URLから直接表示できます。
画像ファイルは取得・保存・転載せず、閲覧時の外部通信を明記します。候補と配置は[次の作業](next-work.md)の#127の範囲に従います。
コードのlicenseから元記事や生成Noteの再配布条件を自動推定しません。
個別の条件や取り下げ要求があれば、該当Noteの配布を明示して扱います。
ユーザーの公開方針を、第三者から個別許諾を取得した証明としては記録しません。

公開前にNoteの内容境界・出典・打切り表示・危険な埋込み・秘密の混入を検査します。
未解決の対象は成功snapshotへ混ぜず、明示して確認する扱いにします。
この確認は人力Vaultの公開判断に及びません。

過去のsource確認とNote品質の実施記録は[履歴](archive/README.md)に保存しました。
現行の要件と配布境界は[仕様書](specification.md)と[公開・配布](publication.md)を参照してください。
