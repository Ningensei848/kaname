# Nano Banana Pro（Gemini 3 Pro Imageモデル）の開発者向け提供開始

> [!abstract] AI要約
> Google DeepMindは、新しい画像生成・編集モデルである「Nano Banana Pro」（[[Gemini 3 Pro]] Image）の開発者向け提供開始を発表した。[[Gemini 3 Pro]]をベースにした高忠実度な同モデルは、[[Google AI Studio]]のGemini APIおよびGoogle Cloudの[[Vertex AI]]を通じて有償プレビューとして提供が開始されている。物理演算や構図の高度な制御、2K・4K解像度、最大5人までのキャラクターの一貫性保持、複数の入力画像をブレンドする機能などを備える。また、Google検索によるグラウンディング機能や高度なテキスト描画、ローカライズ、画像編集機能を持ち、すべての生成・編集画像には[[SynthID]]デジタル透かしが組み込まれている。

![Gemini 3 Pro Image Text to Image AI benchmark bar chart compared to other leading competitors](<https://storage.googleapis.com/gweb-uniblog-publish-prod/images/gemini-pro-image__benchmarks__te.width-1200.format-webp.webp>)

## 重要ポイント

- Nano Banana Pro（[[Gemini 3 Pro]] Image）は[[Gemini 3 Pro]]ベースの高忠実度な画像生成・編集モデルである。
- [[Google AI Studio]]のGemini APIおよび[[Vertex AI]]で有償プレビューとして提供されている。
- 物理演算、照明、カメラ、フォーカス、構図の高度な制御が可能で、2K・4Kの高解像度をサポートする。

![Image showing a side by side of an input image of the silhouette of a man with scattered sun rays and an output image where the same image with more volumetric lighting using AI](<https://storage.googleapis.com/gweb-uniblog-publish-prod/images/Final_NanoBanana_replacelighting.width-1200.format-webp.webp>)
- Google検索のグラウンディング機能を活用してリアルタイムのWebコンテンツに基づく正確な出力を実現している。
- [[SynthID]]デジタル透かしがすべての生成・編集画像に直接組み込まれている。
