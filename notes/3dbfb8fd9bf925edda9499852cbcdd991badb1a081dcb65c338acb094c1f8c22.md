# 初心者向けGitHub Copilotアプリ：キャンバスを使ったカスタムワークフローの構築方法

> [!abstract] AI要約
> GitHub Copilotアプリのキャンバス機能（キャンバス拡張）を利用することで、開発者はプレーンテキストで自身の望むワークフローやインターフェースを記述し、エージェントと共有可能なカスタムUIを動的に生成できます。カンバンボード、チェックリスト、ダッシュボードなどのレイアウトを手動でのコーディングやデザインなしで構築でき、エージェントとの双方向のコラボレーションを通じて柔軟なアップデートが可能です。作成したキャンバスは拡張機能として保存され、チームでの共有や個人用のワークフローとして再利用できます。

## 重要ポイント

- プレーンテキストによるプロンプト（/create-canvasスキル）でカスタムUIを自動生成できる
- キャンバスは双方向であり、人間とAIエージェントの双方が同時に状態を更新し共有できる
- 作成したキャンバスは拡張機能として保存され、プロジェクトのチームメンバーと共有または個人用として再利用できる
