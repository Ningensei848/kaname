# 初心者向けGitHub Copilotアプリ：キャンバスを使ったカスタムワークフローの構築方法

> [!abstract] AI要約
> GitHub Copilotアプリの「キャンバス（キャンバス拡張）」機能を使用すると、開発者はプレーンテキストで希望のインターフェイスを指定し、カスタムワークフローに合わせたライブサーフェスを構築できます。カンバンボード、課題トリアージボード、リリースチェックリスト、ダッシュボードなどをコードを書かずに作成可能です。エージェントと人間が双方向で同時に操作・更新できる共有ホワイトボードのように機能し、作成したキャンバスは拡張機能として保存し、チームや個人で共有して再利用できます。

## 重要ポイント

- プレーンテキストで記述するだけで、GitHub Copilotアプリ内にカスタムUI（キャンバス）を作成できる。
- /create-canvasスキルをエージェントセッションで呼び出し、ワークフローや操作権限を自然言語で指示する。
- 人間とエージェントが双方向で同時にキャンバスの状態を更新し、コラボレーションできる。
- 作成したキャンバスは拡張機能として保存し、プロジェクトチームでの共有や個人用としての利用が可能。
