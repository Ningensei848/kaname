# 初心者向けGitHub Copilotアプリ：キャンバスを使ったカスタムワークフローの構築方法

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。
> 記事後半の論点が含まれない場合があります。記事全体の確認には出典URLを参照してください。

> [!abstract] AI要約
> GitHub Copilotアプリの「キャンバス（キャンバス拡張機能）」機能を使用すると、開発者はプレーンテキストで希望のインターフェースを指定し、かんばんボードやダッシュボードなどのカスタムワークフローを自動生成できます。/create-canvasスキルを用いて作成するこのキャンバスは、ユーザーとエージェント双方が同時に操作できる双方向の共有インターフェースとして機能します。エージェントは作業の進行に合わせてキャンバスを更新でき、ユーザーはボタンやカードなどのコントロールを使って直接変更を加えることが可能です。作成されたキャンバスは拡張機能として保存され、個人用としてだけでなくチームメンバーと共有してプロジェクトで再利用することもできます。

## 重要ポイント

- プレーンテキストで指示するだけで、コードを書かずにカスタムUI（キャンバス）を生成できる。
- /create-canvasスキルを使用し、ワークフローやUIの要件を記述することで作成が可能。
- 人間とAIエージェントが双方向に操作・更新できるライブの共有インターフェースとして機能する。
- 作成したキャンバスは拡張機能として保存し、個人またはチームで共有して再利用できる。
