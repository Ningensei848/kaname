# GISTの紹介：スマートサンプリングの次の段階

> [!abstract] AI要約
> Google Researchの研究者であるMorteza Zadimoghaddam氏とMatthew Fahrbach氏によって NeurIPS 2025 で発表された「Greedy Independent Set Thresholding \(GIST\)」は、データの多様性と有用性を同時に最大化する高品質なデータ部分集合を選択するための新しいアルゴリズムである。現代の機械学習では、膨大で複雑なデータセットの処理が課題となっており、単一の訓練タスクに向けて代表的な小規模グループを選ぶ「サブセット選択」が不可欠である。しかし、重複を避けるための「最大最小多様性」と情報の網羅性を表す「単調劣モジュラー関数」による「有用性」は相反する目標であり、これを最適化することはNP困難な問題として知られていた。GISTは、多様性のコンポーネントをしきい値化し、バイクライテリア貪欲アルゴリズムを用いることで、この困難なトレードオフを効率的に近似する。理論的には、最適な解の少なくとも半分の価値を持つ部分集合を見つけることを保証する初のアルゴリズムであり、ImageNetを用いたResNet-56の画像分類タスクなどの実世界の実装においても、既存の手法と比較して高い分類精度を達成している。また、部分集合の選択自体は非常に高速であり、大規模な機械学習のトレーニングパイプラインへの統合に実用的である。

## 重要ポイント

- GIST（Greedy Independent Set Thresholding）は、データの多様性と有用性を両立させながら高品質なサブセットを選択する新しいアルゴリズムである。
- 最適なサブセット選択がNP困難である問題に対し、多様性のしきい値化とバイクライテリア貪欲アルゴリズムを組み合わせて効率的に近似する。
- 最適な解の少なくとも半分の価値を保証する数学的保証を初めて提供し、ImageNet等での画像分類において既存手法を上回る精度を実現した。
