# GISTの紹介: スマートサンプリングの次なる段階

> [!abstract] AI要約
> 現代の機械学習において、膨大で複雑なデータセットから高品質なデータ部分集合を効率的に選択することは重要な課題である。Google ResearchはNeurIPS 2025にて、データの多様性と有用性を同時に最大化する新アルゴリズム「GIST（Greedy Independent Set Thresholding）」を発表した。GISTは、データの非冗長性を確保する「max-min多様性」と、タスクに対する情報の網羅性を測る「単調劣モジュラー関数による有用性」という、しばしば矛盾する2つの目的を同時に満たす最適化問題を解決する。完璧な部分集合の探索がNP困難であるため、GISTは距離閾値を用いた多様性の分離と、独立集合問題の二基準貪欲近似（bicriteria greedy algorithm）を組み合わせることで、効率的かつ数学的な保証を伴う解の導出を実現している。ImageNetを用いた画像分類タスクなどの評価において、GISTを用いた単項データダウンサンプリングは従来の手法（ランダム、マージン、k-centerなど）と比較して優れた分類精度を達成し、大規模なトレーニングパイプラインへの統合にも耐える高速な処理時間を実証している。

## 重要ポイント

- GISTはデータの多様性と有用性を同時に最大化し、数学的保証を提供する新しいスマートサンプリングアルゴリズムである。
- データ選択におけるmax-min多様性と単調劣モジュラー関数による有用性のトレードオフというNP困難な課題を、閾値処理と二基準貪欲近似の組み合わせで解決する。
- ImageNetを用いた画像分類実験において、既存のサンプリング手法と比較してより高いモデルのトップ1分類精度を達成した。
