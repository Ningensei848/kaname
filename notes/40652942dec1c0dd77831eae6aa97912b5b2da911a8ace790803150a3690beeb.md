# TitansとMIRAS：AIの長期記憶を拡張する新しいアーキテクチャと理論的枠組み

> [!abstract] AI要約
> Google Researchは、AIモデルの長期記憶と超長コンテキスト処理を改善するための新しいアーキテクチャ「Titans」と、その理論的枠組み「MIRAS」を発表した。従来のTransformerは長文脈において計算コストが爆発的に増加し、線形RNNや状態空間モデル（SSM）は固定長圧縮による情報損失の課題を抱えていた。Titansは、リカレントニューラルネットワークの高速性と、Transformerの精度を組み合わせ、多層パーセプトロン（MLP）をベースにした深層長期記憶モジュールを採用する。最大の特徴は「サプライズ・メトリクス（驚き指標）」であり、モデルの予測と新しい入力の誤差を勾配として計算し、文脈を大きく変える重要な情報のみを選択的に長期記憶へ永続化する。また、モーメンタムや適応的な重み減衰（忘却ゲート）により、効率的な情報管理と長大なシーケンスへの対応を実現している。一方、MIRASは多様な配列モデリング手法を統一的に捉える理論的枠組みであり、記憶アーキテクチャ、注意バイアス、保持ゲート、記憶アルゴリズムの4つの選択肢によってモデルを定義する。従来の平均二乗誤差（MSE）中心のパラダイムを超え、非ユークリッドな目的関数や正則化を探求することで、ロバストな特性を持つ「YAAD」「MONETA」「MEMORA」といった派生モデルが生み出された。BABILongベンチマークなどの評価では、TitansがGPT-4などの既存の強力なモデルを上回る超長コンテキスト推論性能を示し、200万トークンを超えるコンテキストウィンドウへの拡張性や、テキスト以外のゲノムデータ、時系列予測への汎用性も実証されている。

![A diagram illustrating a neural architecture with three layers: Contextual Memory \(learning\), Core \(in-context learning\), and Persistent Memory \(fixed weights\).](<https://storage.googleapis.com/gweb-research2023-media/images/Titans-1-Overview.width-1250.png>)

## 重要ポイント

- Titansは、多層パーセプトロンを用いた深層長期記憶モジュールにより、高速なRNNの利点とTransformerの精度を両立させる。

![Two line charts showing that LMM and MM models maintain lower perplexity than Mamba as sequence length increases across 360M and 760M parameter scales.](<https://storage.googleapis.com/gweb-research2023-media/images/Titans-3-Performance1.width-1250.png>)
- サプライズ・メトリクス（驚き指標）とモーメンタム・適応的重み減衰を活用し、文脈の変化が大きい重要情報だけを選択的に記憶・忘却する。
- MIRASは配列モデリングを統一的に説明する理論的枠組みであり、MSEに依存しない非ユークリッドな最適化によりYAADなどの新モデルを導出する。
- TitansはBABILongベンチマーク等においてGPT-4を上回る長文脈推論性能を示し、200万トークン超のコンテキストウィンドウに対応する。
