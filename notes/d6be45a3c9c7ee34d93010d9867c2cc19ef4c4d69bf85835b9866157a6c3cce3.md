# チャットが不適切なUIである理由とキャンバスの活用

> [!abstract] AI要約
> AIの普及から3年が経過し、大規模言語モデル（LLM）との主な対話インターフェースとしてチャットボットが広く使われていますが、タスク志向の作業においては必ずしも最適とは言えないケースが存在します。スティーブン・ピンカー氏の指摘するように、チャットは最初の普遍的なソリューションとして機能してきたものの、ユーザーが具体的な目的を持つ場合には限界があります。GitHub Copilotアプリでは、この課題を解決するために「キャンバス」と呼ばれるカスタマイズ可能なUIが導入されています。キャンバスは、ブラウザのクロームなしで動作するフルスタックアプリケーションであり、エージェントとサーバー間で双方向通信を行うことで、従来のチャットよりも柔軟で強力なユーザー体験を提供します。

## 重要ポイント

- AIとの対話における主なインターフェースであるチャットは、タスク志向の作業において不適切なUIになる場合がある。
- GitHub Copilotアプリで導入されている「キャンバス」は、ブラウザの制約なしで動作するフルスタックアプリケーションである。
- キャンバスとAIエージェントの間で双方向通信を行うことにより、通常のプログラムと同様の柔軟な操作と問題解決が可能になる。
