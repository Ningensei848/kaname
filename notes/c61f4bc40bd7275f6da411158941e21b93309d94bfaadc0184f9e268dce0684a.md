# Diffusion ControllerによるAI画像生成の統合と簡素化の仕組み

> [!abstract] AI要約
> Google Researchが発表したDiffusion Controllerは、テキストからの画像生成プロセスをスムーズな連続制御問題として再定義し、生成の最適化手法を統合するフレームワークです。従来、推論時のガイダンスや重いパラメータ効率的微調整などの手法がバラバラに扱われていたのに対し、基本モデルを凍結したまま軽量な「ステアリングダンパー」ネットワークを外付けすることで、モデルの安定性を保ちながらユーザーの意図や選好への適合性を高めます。これにより、複雑なプロンプトでも画像全体の品質を損なわずに正確な制御が可能になります。実験では、教師あり微調整（SFT）、報酬加重損失（RWL）、PPOの各学習体制において、人間選好スコア（HPS-v2）や人間の評価で既存のLoRAなどのベースラインを上回る勝率を記録しました。さらに、ブラックボックスやグレーボックス環境でも機能し、推論時のパラメータ調整によって制御強度を動的に変更できる柔軟性も備えています。

![A visual comparison matrix showing AI-generated images of a cat, a bluejay, and a lizard created by Pretrained, LoRA, and "Ours" models based on specific text prompts.](<https://storage.googleapis.com/gweb-research2023-media/images/DiffusionController1_VisualMatrix.width-1250.jpg>)

## 重要ポイント

- 画像生成の全プロセスを連続制御問題として捉え、推論時ガイダンスとファインチューニングの手法を数学的に統合する。
- ベースモデルを凍結し、軽量な「ステアリングダンパー」ネットワークを追加することで、高品質な画像を維持しながら効率的な制御を実現する。

![A system architecture diagram illustrating the flow of data from an input through a frozen pretrained backbone and a trainable Diffusion Controller side network to produce a combined score.](<https://storage.googleapis.com/gweb-research2023-media/images/DiffusionController2_BackboneFrozen.width-1250.png>)
- SFT、RWL、PPOの各学習体制におけるHPS-v2評価や人間による評価において、LoRAなどの従来手法を上回る勝率を達成した。

![Three line graphs plotting HPS Win Rate against training steps, demonstrating that various Diffusion Controller models consistently outperform the LoRA baseline over time.](<https://storage.googleapis.com/gweb-research2023-media/images/DiffusionController3_HPS-v2WinRate.width-1250.jpg>)
- 推論時に制御強度のパラメータを調整することで、画像安定性を損なわずにプロンプトへの適合度を動的かつ柔軟に変更できる。
