# Cloudflare、AIコーディングエージェント向けにWebサイトのセキュリティ設定を自動化する「Turnstile Spin」を発表

> [!abstract] AI要約
> Cloudflareは、プライバシー重視のクライアント側チャレンジ「Turnstile」の導入をAIエージェント経由で自動化する新機能「Turnstile Spin」を発表した。Turnstileはフロントエンドでのウィジェット表示とバックエンドでの[[Siteverify API]]呼び出しという2ステップの導入が必要だったが、AIの普及に伴うアプリケーション開発の迅速化と攻撃の自動化に対応するため、Spinがエージェントを介してこのプロセスを統合・自動化する。Spinは、新規インストール、既存ウィジェットのバックエンド検証漏れの修復、他社製CAPTCHAからの移行という3つのコンテキストに適応し、[[Claude Code]]、[[Cursor]]、Codexなどのコーディングエージェントと連携してコードベースに直接変更を適用する。Cloudflareのダッシュボード、Wrangler、またはパブリックなスキルURLから利用でき、7月のリリース以降すでに65,000件以上のウィジェット作成が記録されている。

## 重要ポイント

- Turnstile Spinは、AIコーディングエージェントを活用してTurnstileのフロントエンドとバックエンドの統合を自動化する新機能である。

![Use your preferred coding agent to install Turnstile, as seen here in a sped-up GIF.](<https://blog.cloudflare.com/_emdash/api/media/file/01M39YTQ4AP4XVBR544QYNYSYN.01M39YTR2QFV5NEBMV0S95S5FA.gif>)
- 新規インストール、バックエンド検証が未設定のウィジェット修復、他社製CAPTCHAからの移行の3つの状況に対応する。

![Use Spin to fix the implementation of existing widgets.](<https://blog.cloudflare.com/_emdash/api/media/file/01M39YXJV9H1BH7F3372PRYJR1.01M39YXKKYY4B93K0KYVJGPJCX.gif>)
- コードはCloudflareへ送信されず、手持ちのコーディングエージェントが承認された変更を直接コードベースに適用する。
- Cloudflareダッシュボード、Wrangler、またはパブリックなスキルURLから起動でき、リリース後短期間で65,000件以上のウィジェット作成を記録している。
