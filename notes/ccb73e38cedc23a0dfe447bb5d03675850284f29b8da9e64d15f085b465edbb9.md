# Flint-interactive: インラクティブなデータ視覚化を作成するための言語

> [!abstract] AI要約
> Flint-interactiveは、AI生成のチャートに豊かな対話性を持たせるための新しい言語です。従来、AIによるインタラクティブな視覚化の作成は、高い生成コストや低い信頼性といった課題がありましたが、Flint-interactiveではコンパイラが視覚ロジックとインタラクションロジックを分離することで、この問題に対処しています。ユーザーやAIエージェントは高水準な[[セマンティックイベント]]と更新演算子を用いて振る舞いを定義でき、レンダラー固有のマークを直接操作することなく複雑なインタラクションを構築できます。チャット環境でのMCP統合によるチャート生成や、ダッシュボードでの外部要素との連携、プログラミングAPIを通じたカスタムインタラクションの作成など、多様なユースケースに対応します。

## 重要ポイント

- Flint-interactiveは、AIエージェントがユーザーの操作に応じるインタラクティブなデータ視覚化をより信頼性高く作成できるようにする言語である。

![graphical user interface, chart](<https://www.microsoft.com/en-us/research/wp-content/uploads/2026/10/NEW_Flint-Figure.png>)
