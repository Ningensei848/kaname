# Generative UI: あらゆるプロンプトに対してリッチでカスタムなビジュアル対話型ユーザー体験を提供

> [!abstract] AI要約
> Google Researchは、AIモデルがコンテンツだけでなくユーザー体験全体を動的に生成する新機能「Generative UI」を発表しました。この実装では、ユーザーの質問や指示に応じて、Webページやゲーム、ツールなどのインタラクティブなUIを自動作成します。[[Gemini 3 Pro]]モデルをベースに、ツールアクセス、システム指示、ポスト処理を組み合わせることで実現しており、Geminiアプリの「動的ビュー」「ビジュアルレイアウト」や、Google検索のAIモード（米国の一部のPro/Ultra加入者向け）に実験的に導入されます。人間の評価による調査では、生成速度を除けば、Generative UIの出力は標準的なLLMの出力よりも高く評価されていることが示されています。

## 重要ポイント

- [[Gemini 3 Pro]]をベースにし、ツールアクセス、システム指示、ポスト処理を組み合わせて動的なUIを生成する。

![Flowchart illustrating the process for generating a web page. The LLM takes input from the user prompt taking into account underlying system instructions, and utilizes Tools where needed. It outputs HTML/CSS/JS to the user's browser.](<https://storage.googleapis.com/gweb-research2023-media/images/GenUI-4-Overview.width-1250.png>)
- Geminiアプリの動的ビューやGoogle検索のAIモードに実験的に導入され、カスタムなインタラクティブ体験を提供する。
- 人間の評価において、生成速度を無視すれば、Generative UIによるインターフェースは標準的なLLM出力よりも強く好まれている。
