# CSSの配信量を増やしてサイトのパフォーマンスを向上させる方法

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。

> [!abstract] AI要約
> GitHubは、2023年以降にページ上のコンポーネント数急増に伴って発生したクライアントサイドでのスタイル初期化遅延、SSR（サーバーサイドレンダリング）のパフォーマンス低下、スタイル更新の肥大化という課題に対処するため、CSS-in-JSからCSS Modulesへの完全移行を実施した。Primerデザインシステムを活用し、ネイティブCSSの機能を活かしつつカプセル化や名前空間の分離を実現するCSS Modulesを採用することで、クライアントおよびサーバー側でのランタイムコストを完全に排除し、ページHTMLと一緒に静的なCSSスタイルシートとして配信する仕組みへと移行した。これにより、パフォーマンスを改善しながら、既存システムへの影響を最小限に抑えた段階的な移行を達成している。

## 重要ポイント

- 2023年以降、ページ上のコンポーネント数増加に伴いCSS-in-JSによるクライアントおよびサーバーのパフォーマンス低下が発生した
- Primerデザインシステムを使用し、ネイティブCSSの利点とカプセル化を両立するCSS Modulesへ完全に移行した
- CSS Modulesの導入によりクライアントやサーバーでのランタイムコストが排除され、スタイルシートとしてHTMLと一緒に配信されるようになった
- 大規模なシステム停止を防ぐため、安全かつ段階的なインクリメンタル移行戦略が採用された
