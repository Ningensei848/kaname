# 言語識別機能の強化が多言語音声モデルの言語学習を改善する

> [!abstract] AI要約
> 多言語の自己教師あり音声モデルは、データ予算が同じ場合でも単言語モデルに劣ることが知られている。Apple Machine Learning Researchの研究では、事前学習時にモデルの[[言語識別]]能力を強化することで、クロス言語の知識共有を維持しつつ、連続的な音声および高次の言語的尺度における多言語の性能差を大幅に縮小または解消できることが示された。英語とフランス語を用いた[[HuBERT]]の制御実験において、補助的な言語分類器と言語ごとのk-meansターゲットという2つの介入を検証したところ、バイリンガルベースラインと比較して音素識別誤差（phone-ABX）が11.6%から10.4%に改善し、単言語モデルの10.8%を上回る結果となった。さらに、語彙性能（[[sWUGGY]]）は52.1%から56.7%へ、韻律性能（[[ProsAudit]]）は68.9%から72.9%へ向上した。[[HuBERT]]の学習段階全体を通して、[[言語識別]]の介入は最初のイテレーションで行った場合に最大の効果が得られ、後期の介入では限定的な改善にとどまることが明らかになった。

## 重要ポイント

- 事前学習時にモデルの[[言語識別]]能力を強化することで、多言語音声モデルにおける単言語モデルとの性能差を縮小・解消できる。
- 英語とフランス語の[[HuBERT]]を用いた実験により、補助的言語分類器と言語別k-meansターゲットの有効性が示された。
- 介入により音素識別誤差が11.6%から10.4%に減少し、語彙性能や韻律性能も大幅に向上した。
- [[言語識別]]の導入は[[HuBERT]]の最初のイテレーションで行うのが最も効果的であり、後期や複数回の介入は限定的な改善にとどまる。
