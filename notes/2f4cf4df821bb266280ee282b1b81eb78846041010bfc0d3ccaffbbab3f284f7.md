# GitHub Security Lab Taskflow Agentを活用したAI駆動ファジング

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。

> [!abstract] AI要約
> 本記事では、GitHub Security Lab Taskflow AgentというLLM駆動型セキュリティ自動化フレームワークを基に構築された、C/C++プロジェクト向けの自律型ファジングパイプライン「Fuzzing Taskflow」について紹介しています。開発者がGitHubリポジトリを指定するだけで、AIエージェントがビルドシステムの解析、エントリーポイントの特定、ファジングハーネスの自動生成、AFL++の実行、カバレッジの読み取り、ハーネスの改善、クラッシュのトリアージ、および脆弱性レポートの作成までを人間による介入なしに自動的に実行します。利用にあたっては、LLMが選定する任意のビルドコマンドなどがホスト上で直接実行されるため、Codespaceや使い捨ての仮想マシンといった隔離された環境で実行することが強く推奨されています。

## 重要ポイント

- GitHub Security Lab Taskflow Agentを用いた自律型ファジングパイプライン「Fuzzing Taskflow」が公開された。
- リポジトリを指定するだけで、エントリーポイントの特定からハーネス作成、AFL++の実行、クラッシュのトリアージまでをAIが全自動で行う。
- 任意のビルドコマンドがホスト上で実行されるリスクがあるため、Codespaceなどのディスポーザブルな環境での実行が必須である。
