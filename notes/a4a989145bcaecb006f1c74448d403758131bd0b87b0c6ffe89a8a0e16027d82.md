# Cloudflareがアプリケーションプロファイルによるポジティブセキュリティの強制機能を発表

> [!abstract] AI要約
> Cloudflareは、HTTPリクエストの構造と形式を分析して逸脱を特定し、ポジティブセキュリティポリシーを適用する「Application Profiles」を発表しました。従来のWAFシグネチャによる検知に加え、トラフィックから期待されるリクエスト構造を定期的に学習し、検証レイヤーを常時展開します。パス変数、クエリパラメータ、ヘッダー、Cookie、ボディ構造を対象に、データ型や制約を自動学習し、違反をメタデータとして付与します。管理者はダッシュボードの[[Security Analytics]]でトラフィック傾向を確認でき、カスタムセキュリティルールを作成して非準拠のリクエストをブロックできます。API Security契約者は既存機能の拡張として利用可能であり、非契約者向けにはクローズドベータが提供されています。今後はLLMを活用した重要フィールドの特定や優先順位付け機能の開発も予定されています。

![Request validation enriches the request with metadata that can be used in analytics or Security Rules to enforce blocking of non-conforming requests.](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3B09CFWMN5RMJ4P52K5QEEZ.01M3B09D3DE13C6NY19SCCGXQX.jpg&w=715&h=345&f=webp&fit=cover&position=center>)

## 重要ポイント

- CloudflareはHTTPリクエストの構造を分析しポジティブセキュリティを強制するApplication Profilesを発表しました。

![To enable profiling for a discovered operation, a customer can select “Learn profile” in the overflow menu of an operation. When learning is active, “Learning profile” will be displayed.](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3B09CFRQWTP4W5S1BCN07X2.01M3B09DWCC8TJAYNP51SB3ENS.png&w=715&h=265&f=webp&fit=cover&position=center>)
- トラフィックからパス変数やクエリパラメータなどの期待されるスキーマを自動学習し、非準拠のリクエストを検知します。

![Learned schema can be reviewed directly in the dashboard and downloaded in OpenAPI format.](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3B09EY75HGTKJ084869Z1FF.01M3B09G3R8J7APCEQMP5H1E6J.png&w=715&h=596&f=webp&fit=cover&position=center>)
- 検出結果はメタデータとしてリクエストに付与され、Security Rulesと組み合わせてブロックなどのアクションを柔軟に設定できます。

![Security Analytics shows the outcome of the profile validation on your live traffic. You get visibility without affecting traffic. Blocking invalid requests depends on deploying a rule.](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3B09F8Z0TBJ67BMHRQTA9K3.01M3B09GMCWVTKENJ3VM6G0HEJ.png&w=715&h=406&f=webp&fit=cover&position=center>)
- API Securityの既存ユーザーは利用可能であり、対象外の顧客向けにはクローズドベータ版が提供されています。

![Create a rule to block requests that do not conform with the learned schema profile.](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3B09JH896EEFN63XD2BYFMM.01M3B09KNR0W4AKRJ2P0T68WAV.png&w=715&h=465&f=webp&fit=cover&position=center>)
