# Cloudflare WAFがフルビジネストラランザクション検出とレスポンスルールを発表

> [!abstract] AI要約
> Cloudflareは、ウェブアプリケーションファイアウォール（WAF）に「フルビジネストラランザクション検出」と「レスポンスルール」の2つの新しい機能を導入した。これらは、HTTPリクエストをレスポンスと同時に評価することで、脆弱性悪用の証拠を特定し、オリジンサーバーからの応答がクライアントに届く前にブロックすることを可能にする。従来の機能ではリクエスト単体の検査に留まり、偽陽性を防ぐために厳密な制御が難しかったが、レスポンス側の証拠を組み合わせることで精度の高い保護を実現している。最初の適用例として、最近開示された「[[php2shell]]」脆弱性への対策が含まれており、Freeプランを含むすべてのCloudflare顧客に対して一般提供が開始されている。

![The structure of request and response in Cloudflare’s web application firewall \(WAF\).](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M5E1HSQ4EYHAJEWBHRQJD6KX.png&w=715&h=402&f=webp&fit=cover&position=center>)

## 重要ポイント

- HTTPリクエストとレスポンスを同時に評価するフルビジネストラランザクション検出により、攻撃の成否やデータ露出を正確に判断可能にする。
- レスポンスルールを活用することで、オリジンサーバーの応答がユーザーに到達する前にWAFのブロックページやカスタムレスポンスに置き換えることができる。
- Cloudflare Managed Response Firewall Defaultルールセットを通じ、追加設定なしで全顧客に保護機能が提供される。

![Cloudflare Managed Response Firewall Default runs on every request by default. To reduce the risk of false positives, customers can restrict the scope of the mitigation to a portion of their application.](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M5E1HQ0T2T2QN8P47Q92VQ0W.png&w=715&h=392&f=webp&fit=cover&position=center>)
- リクエストおよびレスポンスのプロパティを組み合わせたカスタムルールを作成し、アプリケーション固有のセキュリティポリシーを構築できる。

![All customers can create response rules by combining both request and response fields.](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M5E1HR792GDJYY7FSHPR72DR.png&w=715&h=378&f=webp&fit=cover&position=center>)
