# 大規模言語モデルの継続学習に向けた新しい知識保持フレームワーク「Sleep」

> [!abstract] AI要約
> Google Researchが提案する「Sleep」フレームワークは、人間が睡眠中に記憶を固定化する仕組みに着想を得て、大規模言語モデル（LLM）の継続学習における破滅的忘却を防ぎながら知識を長期保持するための仕組みです。モデルの動作を「アクティブ（覚醒）フェーズ」と「スリープ（睡眠）フェーズ」の2つに分け、スリープ中に短期記憶を長期的なパラメータへ統合する「メモリコンソリデーション」と、自己改善を促す「ドリーミング」の2段階を実行します。混合専門模型（MoE）や知識蒸留、強化学習を活用することで、パラメータを上書きせずに新しい事実を吸収し、最大1,000万トークンの長文脈理解や、数学的推論、継続的翻訳において優れた性能を発揮することを示しています。

## 重要ポイント

- アクティブフェーズとスリープフェーズを交互に繰り返すことで、LLMの継続学習における破滅的忘却を防止する。
- メモリコンソリデーションにより、短期的な文脈情報をMixture-of-Experts（MoE）などの拡張された長期パラメータへ移行・統合する。

![Flowchart illustrating the Sleep Phase architecture, showing how short-term memory is consolidated into parametric memory.](<https://storage.googleapis.com/gweb-research2023-media/images/LLMSleep1_Framework.width-1250.png>)
- ドリーミング（睡眠中の自己改善）工程を通じて、ランダムな専門家の選択や強化学習による洗練を行い、最適化のランドスケープを改善する。
- 長文脈理解（最大10Mトークン）、継続的翻訳、数学的推論などの評価軸において、既存のベースライン手法を上回る性能を実証した。

![Two bar charts showing that Sleep methods outperform other approaches in class-incremental learning and continual translation.](<https://storage.googleapis.com/gweb-research2023-media/images/LLMSleep2_Results.width-1250.png>)
