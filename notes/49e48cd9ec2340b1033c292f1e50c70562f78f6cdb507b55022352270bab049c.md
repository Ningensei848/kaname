# GitHub CopilotアプリのセッションをVS Codeで継続する方法

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。

> [!abstract] AI要約
> GitHub Copilotアプリで進めていたエージェントセッションを、会話、コード変更、作業コンテキストを維持したまま[[Visual Studio Code]]（VS Code）に移行して継続する方法についての解説記事です。 Copilotアプリでの作業が一段落した後、エージェントの変更内容をローカルで確認・調整し、テストや微調整を行いたい場合に役立ちます。記事では、前提条件としてCopilotアプリやVS Codeのインストール、同一のGitHubアカウントへの接続、リポジトリの権限などを確認した上で、Copilotアプリの画面から「Open in VS Code」を選択し、ワークツリーやCopilotサイドバーを通じてセッションの文脈や差分を保持したまま開発をシームレスに引き継ぐ手順を説明しています。

## 重要ポイント

- GitHub Copilotアプリのセッションを、会話やコード変更、作業コンテキストを維持したままVS Codeで開くことができます。
- 作業を開始する前に、両方のツールへのサインインやリポジトリへのアクセス権、同一アカウントでの接続を確認する必要があります。
- Copilotアプリのメニューから「Open in VS Code」を選択することで、エージェントが使用していた独立したワークツリーとセッション履歴をエディタ側に引き継げます。
