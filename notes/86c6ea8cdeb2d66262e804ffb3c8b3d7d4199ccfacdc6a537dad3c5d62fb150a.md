# Merkle Tree Certificatesを活用した耐量子認証局（CA）の構築に向けて

> [!abstract] AI要約
> インターネットにおける耐量子暗号（PQ）への移行では、従来の証明書チェーンをそのまま適用するとパフォーマンスが大幅に低下するスケーリング課題が存在します。Cloudflareは、この課題を解決するため、IETF PLANTSワーキンググループの仕様に基づく「[[Merkle Tree Certificates]]（MTC）」を採用し、2027年初頭のChrome向け耐量子ルートストアへの包含を目標として標準的なMTC発行を無料で提供する認証局（CA）の立ち上げを進めています。MTCは、発行とログ記録を一体化させることで証明書の透明性を標準機能として組み込み、個別の証明書に署名する代わりに追記型のマークルツリーのルートに署名します。これにより、クライアントは軽量な包含証明書を用いて効率的に検証を行えます。また、独立したミラーリング署名者による一貫性の検証や、帯域を節約するランドマーク最適化を活用することで、TLSハンドシェイク時のオーバーヘッドを大幅に削減します。Chrome Betaでの実験では、MTCが実用可能であり、古典的な署名チェーンと比較して中央値で9%高速化することが確認されました。今後は、本番環境でのスケーリング検証や、独立したモニターによる監査、ブラウザや多様なエコシステムとの連携が重要な課題となります。

## 重要ポイント

- Cloudflareは2027年初頭のChrome向け耐量子ルートストアへの包含を目標に、標準的なMTC発行を無料で行う新しい認証局（CA）の設立を計画しています。

![記事の画像](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3MX1PSVH1CJ1PY7H7PKPQX4.png&w=715&h=233&f=webp&fit=cover&position=center>)
- [[Merkle Tree Certificates]]（MTC）は証明書の発行とログ記録を一体化し、マークルツリーのルートに対して署名を行うことで耐量子暗号の巨大な署名サイズによるスケーリング問題を解決します。

![記事の画像](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3MX1R818H67HP9AJS1QNAND.png&w=715&h=420&f=webp&fit=cover&position=center>)
- 証明書はスタンドアロン形式のほか、帯域を効率化するランドマーク相対形式に対応し、TLSハンドシェイク時のデータ転送量を1kB未満に抑えることが可能です。

![記事の画像](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3MX1M0Z4J12THF1PT2M52CZ.png&w=715&h=452&f=webp&fit=cover&position=center>)
- Chrome Betaを用いた実験により、MTCが実運用で機能し、従来の署名チェーンと比較してレイテンシが改善することが実証されました。

![記事の画像](<https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01M3MX1NGZQ01K3ZP2SSRNVK9A.png&w=715&h=359&f=webp&fit=cover&position=center>)
