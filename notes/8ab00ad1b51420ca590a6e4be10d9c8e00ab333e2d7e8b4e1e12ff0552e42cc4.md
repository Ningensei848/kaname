# 推論のボトルネックを迂 Salvage：Retrieve-for-Trainによる複雑なAI検索の高速化

> [!abstract] AI要約
> 現代の検索や推薦アプリケーションでは、単一の最適な結果ではなく、多様性や補完性、網羅性などの高次なセットレベルの特性を満たす一貫した結果のセットを返すことが求められています。しかし、LLMを用いた従来のクエリ分解は、パラフレーズの崩壊や、大規模な思考予算を消費する自己回帰的なレイテンシのボトルネックという課題を抱えていました。Google Researchの論文「Efficient, Property-Aligned Fan-Out Retrieval via RL-Compiled Diffusion」で提案された「Retrieve-for-Train」フレームワークは、報酬からデータへのコンパイルフレームワークを採用し、オフラインの強化学習（RL）によって報酬に整合したファンアウトを探索・監督データにコンパイルします。この学習された探索行動を軽量な拡散リトリーバー（53.9Mパラメータの拡散モデル）に蒸留することで、テスト時の思考トークンのオーバーヘッドなしに、高効率な単一パスのクエリファンアウトを実現します。本手法は、ファンアウト言語モデルの訓練、監督データの合成、そして拡散ベースのファンアウト・リトリーバーの訓練という3つのステップで構成され、グラウンデッドネス、多様性（Vendiスコア）、アライメントの複合報酬を用いて最適化されます。実験の結果、OARおよびWSCRタスクにおいて、標準的な検索やゼロショットベースラインを上回るパフォーマンスを維持しつつ、自己回帰的アプローチと比較して12倍から20倍の高速化（サブ秒から数秒のレイテンシ）を達成しました。

![A three-step framework diagram for a machine learning model, detailing Fan-Out LM Training, Supervision Synthesis, and Diffusive Retriever Training.](<https://storage.googleapis.com/gweb-research2023-media/images/Retrieve-for-Train1_framework_overview.width-1250.png>)

## 重要ポイント

- Retrieve-for-Trainフレームワークは、オフラインの強化学習を用いて報酬に整合したクエリのファンアウトを探索し、監督データにコンパイルすることで推論時の計算コストを削減する。
- グラウンデッドネス、Vendiスコアによる多様性、アライメントの複合報酬（相互カウンターアンカー）を使用することで、パラフレーズの崩壊や報酬ハッキングを防ぎつつ高品質なサブクエリを生成する。
- 53.9Mパラメータの拡散モデルを用いることで、非自己回帰的な単一パスでターゲットの埋め込みを直接サンプリングし、自己回帰型モデルで発生する最大50秒のレイテンシをサブ秒から数秒へと大幅に短縮する。
