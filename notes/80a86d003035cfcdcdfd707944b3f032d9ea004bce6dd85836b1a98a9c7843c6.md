# ミックスかチューニングか：データ制約のある環境におけるバイリンガル事前学習のハイパーパラメータ探索に対する優位性

> [!abstract] AI要約
> 世界の大半の言語において、言語モデルの事前学習は訓練データを何度も繰り返すデータ制約環境で行われ、汎化性能が低下する課題があります。これに対し、高体重減衰などの積極的なハイパーパラメータチューニングと、高リソースの補助言語データを混ぜるという2つの改善策が存在します。[[Apple Machine Learning Research]]の研究では、アラビア語を低リソースのターゲット、英語を補助言語とし、1,500万から14.3億パラメータまでの4つのモデル規模で約1,000回の事前学習実験を通じて両者を比較しました。その結果、第1にデータの混合はハイパーパラメータチューニングよりも[[検証ロス]]および[[下流タスク精度]]の両方で大きな改善をもたらし、その差はモデルサイズとともに拡大することが判明しました。第2に、混合の効果は[[検証ロス]]で2〜3倍、[[下流タスク精度]]で2〜13倍の独自ターゲットデータ追加に相当する性能向上をもたらします。第3に、ターゲット言語の[[検証ロス]]は、混合がもたらす知識の寄与を過小評価することが示されました。実用的な推奨事項として、高リソース言語の混合、ハイパーパラメータチューニングよりも混合比率の優先、およびμPを用いた小型プロキシモデルからのハイパーパラメータ転移が挙げられます。

## 重要ポイント

- 低リソース言語の事前学習において、データの混合はハイパーパラメータチューニングよりも[[検証ロス]]と[[下流タスク精度]]の両方で大きな改善をもたらし、モデルサイズが大きいほどその差が拡大する。
- データ混合による性能向上は、[[検証ロス]]において2〜3倍、[[下流タスク精度]]において2〜13倍の独自ターゲットデータを追加した効果に匹敵する。
- ターゲット言語の[[検証ロス]]は、混合が提供する新しい知識の寄与を過小評価するため、[[検証ロス]]単体では混合の真の価値を見誤る可能性がある。
