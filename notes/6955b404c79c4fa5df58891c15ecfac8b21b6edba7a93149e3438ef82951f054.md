# TabFMの紹介：表形式データ向けゼロショット基盤モデル

> [!abstract] AI要約
> Google Researchは、表形式データの分類および回帰ワークフローを簡素化する新しいゼロショット基盤モデル「TabFM」を発表しました。従来のXGBoostやランダムフォレストなどのツリーベース手法は手動での特徴量エンジニアリングやハイパーパラメータ最適化を必要としますが、TabFMはコンテキスト内学習（ICL）の枠組みを用いることで、事前のモデル学習なしに初見のテーブルに対して単一のフォワードパスで高精度な予測を生成します。そのアーキテクチャは、構造的因果モデルを用いて生成された数億件の合成データで事前学習され、行方向と列方向の交互アテンション、行圧縮、および行ベクトルに対するトランスフォーマーによる効率的なICLを組み合わせたハイブリッド設計を採用しています。さらに、TabArenaベンチマークでは優れた性能を示し、Google Cloud BigQueryにもネイティブ統合されSQLクエリを通じて利用可能です。

## 重要ポイント

- TabFMは、表形式データの分類と回帰のためのゼロショット基盤モデルであり、単一のフォワードパスで予測を行う。
- 行・列の交互アテンションと圧縮された行ベクトルに対するアテンションを組み合わせたハイブリッドなアーキテクチャを採用している。
- プライバシーやデータ不足の課題を克服するため、構造的因果モデルを用いて生成された数億件の合成データで事前学習されている。
- Google Cloud BigQueryにネイティブ統合され、カスタムのモデル訓練なしにSQL（AI.PREDICT）から利用できる。
