# TabFMの紹介：表形式データ向けゼロショット基盤モデル

> [!abstract] AI要約
> [[Google Research]]は、表形式データの分類および回帰タスクに向けたゼロショット基盤モデル「TabFM」を発表しました。従来の機械学習では、[[XGBoost]]などの決定木ベースのアルゴリズムを用いた手動のハイパーパラメータ調整や高度な特徴量エンジニアリングがボトルネックとなっていましたが、TabFMは表形式予測をコンテキスト内学習（ICL）の問題として捉えることでこれを解消します。TabFMのアーキテクチャは、交互の行・列アテンション、行圧縮、およびICLを行うトランスフォーマーを組み合わせたハイブリッド設計を採用しており、2次元で順序のない表データの特性を効率的に処理します。オープンソースの表データの不足を補うため、構造的因果モデル（SCM）を用いて動的生成された数億もの大規模な合成データで事前学習が行われています。[[TabArena]]ベンチマークでは、単一のフォワードパスで予測を行うデフォルト設定と、アンサンブルやチューニングを取り入れた設定の両方で評価され、高いパフォーマンスを示しています。また、TabFMはHugging FaceやGitHubで公開されているほか、Google Cloud BigQueryにも直接統合されており、SQLクエリを用いてカスタムモデルのトレーニングなしで予測を実行することが可能です。

## 重要ポイント

- TabFMは表形式の分類・回帰タスクのためのゼロショット基盤モデルであり、手動での特徴量エンジニアリングやハイパーパラメータ調整を不要にする。
- モデルのアーキテクチャは交互の行・列アテンション、行圧縮、ICLを行うトランスフォーマーを組み合わせたハイブリッド設計を採用している。

![TabFM\_Architecture](<https://storage.googleapis.com/gweb-research2023-media/images/TabFM_Architecture.width-1250.png>)
- オープンソースの表形式データの不足を克服するため、構造的因果モデル（SCM）を用いて生成された数億規模の合成データで事前学習されている。
- [[TabArena]]ベンチマークでの評価を通じて高い性能を示しており、Hugging FaceやGitHubでの公開に加え、Google Cloud BigQueryにも統合されている。

![TabFM3\_Results](<https://storage.googleapis.com/gweb-research2023-media/images/TabFM3_Results.width-1250.png>)
