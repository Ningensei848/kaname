# AI生成による合成ニューロンが脳マッピングを加速

> [!abstract] AI要約
> [[Google Research]]は、ICLR 2026で発表予定の論文「[[MoGen]]: Detailed neuronal morphology generation via point cloud flow matching」において、AIを活用したニューロンの形態生成モデル「[[MoGen]]」を発表した。コネクトミクス分野では脳の3D配線図を作成するために顕微鏡画像のセグメンテーションが行われるが、AIモデル「[[PATHFINDER]]」の出力結果に対する人間による手動での校正・修正作業が最大のボトルネックとなっている。[[MoGen]]は、点群フローマッチング（[[PointInfinity]]）を応用してランダムな3Dポイント群を現実的な神経の形状へと徐々に変換し、マウスの軸索などを模倣した数百万の合成ニューロン形状を生成する。この[[MoGen]]による合成データを学習パイプラインに10%組み込んだ結果、マウス軸索の再構築におけるエラー率が4.4%減少し、特にマージエラーの削減に寄与した。この数値は、完全なマウス脳のスケールにおいては、人間の専門家による手動校正作業を157人年分削減することに相当する。[[Google Research]]はこの[[MoGen]]をオープンソースとして公開しており、今後は特定の神経タイプの生成や、合成電子顕微鏡画像の作成などを通じてさらなる効率化を目指している。

## 重要ポイント

- [[Google Research]]は、ニューロンの形態を生成するAIモデル「[[MoGen]]」を開発し、ICLR 2026で発表予定である。
- [[MoGen]]は点群フローマッチングを用いて現実的な3D神経形状をシミュレートし、人間の専門家でも実物との区別がつかないレベルの合成データを生成する。
- [[MoGen]]による合成データをAI再構築モデル「[[PATHFINDER]]」の学習に導入することで、再構築のエラー率が4.4%削減された。
- この4.4%のエラー改善は、完全なマウス脳のマッピングスケールにおいて、人間の手動による校正作業を157人年分削減する効果に匹敵する。
