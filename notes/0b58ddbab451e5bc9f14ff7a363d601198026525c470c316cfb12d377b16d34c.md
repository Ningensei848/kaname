# GitHub Copilotのランタイムを、Copilot自身を使ってRustに移行する

> [!abstract] AI要約
> 本記事では、GitHub Copilotのエージェントランタイムを、TypeScriptおよびNode.jsから800,000行以上の本番用Rustへと全面移行した取り組みについて解説しています。移行作業はGitHub CopilotアプリとCopilot CLIを活用し、AIエージェントがコードの大部分を自動生成する形で進行しました。単一の巨大なカットオーバーではなく128件のプルリクエストによってインクリメンタルにマージされ、数か月という短期間で完了しました。これにより、ランタイムのパフォーマンスが大幅に向上し、チームが他の機能拡張にも集中できる環境が整いました。

## 重要ポイント

- GitHub CopilotのエージェントランタイムをTypeScript/Node.jsからRustへと全面移行
- 移行されたコードベースは800,000行以上の本番用Rustコードに到達
- 移行作業の大部分はAIエージェント（Copilot）によって記述された
- 128件のプルリクエストを通じて段階的（インクリメンタル）にメインブランチへマージ
- ランタイムのパフォーマンスが劇的に向上し、少数または単一のエンジニアによる短期間での開発を実現
