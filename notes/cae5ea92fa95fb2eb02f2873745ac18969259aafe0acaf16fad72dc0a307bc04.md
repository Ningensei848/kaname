# ToolGrad：テキスト「勾配」を活用した効率的なツール利用データセット生成

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。

> [!abstract] AI要約
> Google Researchが発表した「ToolGrad」は、従来の「ユーザー質問からツール利用経路を探す」という非効率なアプローチを逆転させ、正解となるツール利用チェーンを先に生成してから対応するユーザープロンプトを注釈する、逆転の発想によるデータ生成フレームワークです。TextGradの概念を適応し、API提案、並列実行、選択、LLMによる更新という4つのモジュールを繰り返すことで、テキスト形式の「勾配」を利用して複雑なAPIワークフローを構築します。ToolBenchを用いた実験では、ToolGradは従来の深さ優先探索手法と比較して、99.8%という非常に高いパス率を低コストで達成しました。また、生成された小規模データセット「ToolGrad-500」でGemma-3モデル（1B、4B、12B）をファインチューニングしたところ、Berkeley Function Calling Leaderboard（BFCL）においてベースモデルの性能を一貫して向上させ、12Bモデルでは一部の最先端プロプライエタリモデルを凌駕するスコアを記録しました。

## 重要ポイント

- ToolGradは、ツール利用の正解を先に生成してからユーザープロンプトを注釈する「答えファースト」のアプローチを採用し、データ生成のコスト削減と高パス率（99.8%）を実現している。
- テキスト「勾配」の概念をプロンプト最適化から拡張し、API提案・実行・選択・更新の4つのモジュールによって複雑なAPIワークフローを段階的に構築する。
- ToolGradデータでファインチューニングされたGemma-3モデルは、Berkeley Function Calling Leaderboard（BFCL）においてベースモデルや他のオープンソース特化モデルを上回る性能を示した。
