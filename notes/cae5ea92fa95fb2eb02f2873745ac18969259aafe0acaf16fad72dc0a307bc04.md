# ToolGrad：テキストベースの勾配を用いた効率的なツール利用データセット生成

> [!abstract] AI要約
> AIエージェントの自動化タスク遂行において、大規模言語モデルに正確なツール利用を学習させるためのデータセット作成は不可欠です。従来の手法は、ユーザー指示から試行錯誤で探索を行うため非効率でした。Google Researchなどの研究チームが発表したToolGradは、解答ファーストのパラダイムを採用し、最初に正確なツール利用チェーンを構築してからユーザープロンプトを注釈付けすることで、約100パーセントの高い通過率と低コストでのデータ生成を実現します。ToolGradは、API候補の提案、並列実行、テキスト勾配としての最適なAPIの選択、クエリの更新という4つのコアモジュールによる反復フレームワークを備えています。[[ToolBench]]のAPIデータベースを用いて生成されたデータセットToolGrad-500で[[Gemma-3]]モデルをファインチューニングした結果、ToolGrad-12Bは[[Berkeley Function Calling Leaderboard]]において最先端の独自モデルやオープンソースの専門モデルを凌駕する性能を達成しました。

![A diagram showing ToolGrad's sequential API mini-batch method achieving a high annotation pass rate compared to failing prior art.](<https://storage.googleapis.com/gweb-research2023-media/images/ToolGrad1_teaser.width-1250.png>)

## 重要ポイント

- ToolGradは、最初に正解のツール利用チェーンを生成してから対応するプロンプトを作成する解答ファーストのデータ生成アプローチを採用しています。
- APIプロポーザ、エグゼキュータ、セレクタ、LLMアップデータという4つのコアモジュールを反復させることで、複雑で有効なAPIワークフローを構築します。

![A flowchart illustrating the ToolGrad workflow, where APIs are proposed, evaluated, and sequentially integrated to update a query and workflow.](<https://storage.googleapis.com/gweb-research2023-media/images/ToolGrad3_workflow.width-1250.png>)
- ToolGrad-500でファインチューニングされた[[Gemma-3]]-12Bモデルは、[[Berkeley Function Calling Leaderboard]]で83.1点を記録し、多くの最先端商用モデルを上回る性能を示しました。

![A bar chart showing ToolGrad consistently improving the tool-calling benchmark scores of 1B, 4B, and 12B base models.](<https://storage.googleapis.com/gweb-research2023-media/images/ToolGrad5_bfclResults.width-1250.png>)

## 資料の位置づけ

本資料は、AIエージェントの訓練に欠かせないツール利用データセットの生成効率と品質を大幅に向上させる新しいフレームワーク「ToolGrad」について解説しています。従来の手法が持つ非効率な試行錯誤型のアプローチを克服し、テキスト勾配を活用して正確なAPIチェーンを低コストで構築する手法を提示しています。大規模言語モデルのポストトレーニングやエージェント開発に関わる研究者やエンジニアにとって、効率的なデータ合成手法の参照先として高い価値があります。
