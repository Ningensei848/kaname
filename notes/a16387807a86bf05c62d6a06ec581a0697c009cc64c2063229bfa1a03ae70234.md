# Vibe Coding XR: XR BlocksとGeminiを活用したAI + XRプロトタイピングの迅速化

> [!abstract] AI要約
> Google Researchが発表した「Vibe Coding XR」は、大規模言語モデルGeminiとオープンソースのXR Blocksフレームワークを組み合わせ、ユーザーの自然言語のプロンプトから物理演算を伴うインタラクティブなWebXRアプリケーションを60秒未満で生成するラピッドプロトタイピングワークフローです。従来は複雑な知覚パイプラインやゲームエンジンの統合が必要だったXR開発において、Geminiの長文脈理解と専用システムプロンプト、テンプレートを活用することで、デスクトップ上のシミュレーション環境やAndroid XRヘッドセット上で直接動作する空間エクスペリエンスの構築を自動化します。数学の学習アプリ、物理実験、化学シミュレーション、量子力学の可視化、XRゲームなどの多様なユースケースにおいて、アイデアから動作するプロトタイピングまでの時間を劇的に短縮することが可能です。

## 重要ポイント

- GeminiとXR Blocksを組み合わせ、自然言語のプロンプトから物理演算対応のWebXRアプリケーションを60秒未満で自動生成する「Vibe Coding XR」ワークフローを発表。
- デスクトップのシミュレーション環境とAndroid XRヘッドセットの両方に対応し、実機デプロイ前の迅速なインタラクションテストが可能。
- 数学、物理、化学、量子力学（シュレーディンガーの猫）、XRゲームなど、多様な教育・エンターテインメント分野への適用事例を確認。
