# Gemini Enterprise Agent Platformのエージェント型RAGによる信頼性の高い応答の実現

> [!abstract] AI要約
> 本記事では、複雑なビジネスワークフローにおけるマルチソースかつマルチホップのクエリに対応するために開発された、Googleの「[[Gemini Enterprise Agent Platform]]」でホストされるエージェント型RAG（[[Cross-Corpus Retrieval]] powered by Agentic RAG）について紹介しています。従来の標準的なRAGでは、情報の不足時に「見つからない」といった不完全な回答になりがちでしたが、エージェント型RAGではオーケストレーター、プランナー、クエリリライター、検索ファンアウトなどの複数エージェントが連携して動的に情報を収集します。特に「十分コンテキストエージェント（Sufficient Context Agent）」が品質管理の役割を果たし、取得された断片、ドラフト、不足部分の分析を繰り返すことで、必要な情報が揃うまで再検索を行います。[[FramesQA]]を用いた評価実験では、単一コーパスおよび4つの異なるコーパスをまたぐクロスコーパス設定の双方において高い精度を達成し、クロスコーパス設定でも90.1%の質問に正解することが示されています。

![AgenticRAG3\_Comparison](<https://storage.googleapis.com/gweb-research2023-media/images/AgenticRAG3_Comparison.width-1250.png>)

## 重要ポイント

- [[Gemini Enterprise Agent Platform]]上でホストされるクロスコーパス検索に対応したエージェント型RAGが導入された
- プランナーやクエリリライター、検索ファンアウトなどの複数エージェントが連携して複雑なクエリを処理する
- 十分コンテキストエージェントが情報の不足箇所を分析し、必要な情報が揃うまで反復的な再検索を実行する
- [[FramesQA]]ベンチマークを用いた実験において、クロスコーパス環境でも単一コーパスに匹敵する90.1%の高精度を達成した
