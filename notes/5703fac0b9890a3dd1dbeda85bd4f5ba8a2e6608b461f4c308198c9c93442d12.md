# Gemini Enterprise Agent PlatformのAgentic RAGによる信頼性の高い応答の実現

> [!warning] 要約対象の制限

> [!abstract] AI要約
> Google ResearchとGoogle Cloudの共同開発による新しい「Agentic RAG（エージェント型RAG）」フレームワークは、従来の単一ステップ型RAGでは対応できなかった複雑なマルチホップおよび複数ソースにわたる企業向けクエリを解決するために設計されました。このマルチエージェント型ワークフローには、オーケストレーター、プランナー、クエリ書き換え、検索ファンアウトの各エージェントに加え、検索結果の十分性を評価して反復的な追加検索を促す「Sufficient Context Agent（十分コンテキストエージェント）」が組み込まれています。これにより、AIが情報不足の際に勝手に推測したり回答を諦めたりすることを防ぎ、必要なコンテキストが集まるまで探索を継続します。FramesQAベンチマークを用いた評価では、複数の不要なデータセットが混在するクロスコーパス環境においても、単一コーパスと同水準の90.1%の正解率を維持し、従来のバニラRAGと比較して事実正確性が最大34%向上することが示されました。本機能はGemini Enterprise Agent Platformのクロスコーパス検索機能としてパブリックプレビューで提供されています。

## 重要ポイント

- 複雑なビジネス上のマルチホップクエリに対応するため、オーケストレーション、プランニング、クエリ書き換え、検索を担うマルチエージェントの仕組みを導入している。
- 「Sufficient Context Agent」が検索されたスニペット、中間ドラフト、不足部分の分析を行い、情報が十分かどうかを判定して反復的な追加検索を制御する。
- FramesQAベンチマークを用いた実験で、複数データソースが混在するクロスコーパス環境でも90.1%の高精度を維持し、事実正確性を最大34%向上させた。
