# Gemini Enterprise Agent PlatformのAgentic RAGで信頼性の高い応答を実現する

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。
> 記事後半の論点が含まれない場合があります。記事全体の確認には出典URLを参照してください。

> [!abstract] AI要約
> Google ResearchとGoogle Cloudの共同開発による新しいエージェント型RAG（Agentic RAG）フレームワークが紹介されています。標準的な1ステップのRAGとは異なり、複雑なエンタープライズ向けのマルチホップクエリやマルチソースの検索に対応するため、オーケストレーター、プランナーエージェント、クエリリライター、検索ファンアウトエージェントなどのマルチエージェントワークフローを採用しています。特に「Sufficient Context Agent（十分コンテキストエージェント）」を導入することで、検索されたスニペットや中間ドラフトを評価し、情報が不足している場合に反復的な追加検索を自律的に行います。FramesQAなどのベンチマークテストでは、従来のVanilla RAGと比較してファクト性に優れた高い精度を達成しており、複数コーパスを跨ぐ検索環境でも単一コーパス並みの正確性を維持します。本機能はGemini Enterprise Agent Platformのクロスコーパス検索機能としてパブリックプレビューで提供されています。

## 重要ポイント

- 複数エージェントが連携して複雑なエンタープライズクエリを計画、書き換え、ルーティングし、情報の間隙を埋める反復的検索を実行する。
- Sufficient Context Agentが検索されたスニペットと中間ドラフトを評価し、情報が十分かどうかを判定して次のアクションを指示する。
- FramesQAベンチマークにおいて、クロスコーパス設定でも高い精度と優れたグラウンディング性能を発揮し、応答の信頼性を大きく向上させる。
