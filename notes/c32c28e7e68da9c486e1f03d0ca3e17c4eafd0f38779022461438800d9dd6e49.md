# オープンソースのAIセキュリティエージェントを使用して24件のAndroid脆弱性を発見した方法

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。
> 記事後半の論点が含まれない場合があります。記事全体の確認には出典URLを参照してください。

> [!abstract] AI要約
> GitHub Security Labのチームは、セキュリティ研究者が効果的なAIプロンプトやワークフローを自動化、パッケージ化、共有できるようにするオープンソースの「GitHub Security Lab Taskflow Agent」を開発しました。カスタムのタスクフロープロンプトを用いてリサーチを段階的なステップに分割することで、LLMが複雑な脆弱性を迅速に発見できるようになり、著者はこれまでに20件以上のAndroidアプリケーションの脆弱性を報告しています。記事では、オープンソースのエージェントを自身のプロジェクトで実行する方法として、Codespaceの立ち上げや監査スクリプトの実行手順が紹介されています。また、Androidアプリ特有の脆弱性に焦点を当てるため、攻撃者制御データが流入する可能性のあるエントリーポイントをモバイル向けと非モバイル向けに分類する「gather\_mobile\_entry\_point\_info.yaml」というタスクフローの追加についても触れられています。

## 重要ポイント

- GitHub Security LabのオープンソースAIセキュリティエージェントを活用し、Androidアプリから24件の脆弱性を発見した。
- タスクフロープロンプトを用いて複雑なリサーチを段階的に分割することで、LLMの脆弱性検出能力を向上させている。
- GitHub Codespace上で専用のスクリプトを実行することにより、開発者や研究者が自前のリポジトリに対して同様の監査を容易に実施できる。
