# オープンソースのAIセキュリティエージェントを使用して24件のAndroid脆弱性を発見した方法

> [!warning] 要約対象の制限
> 入力上限により、変換後の本文の先頭20,000文字だけを要約しています。
> 記事後半の論点が含まれない場合があります。記事全体の確認には出典URLを参照してください。

> [!abstract] AI要約
> GitHub Security Labチームは、セキュリティ研究者が効果的なAIプロンプトやワークフローを自動化・共有できるオープンソースのフレームワーク「GitHub Security Lab Taskflow Agent」を開発しました。著者であるKevin Stubbings氏は、このフレームワークにAndroidアプリ固有の脆弱性に特化した監査タスクフローを追加し、これまでに20件以上の脆弱性を報告しました。記事では、タスクフローの仕組みや、自身のプロジェクトで実行する方法、攻撃者が制御するデータが流入するエントリーポイントを識別してモバイル向けに分離する仕組みについて解説しています。タスクフローは、LLMにコード理解のステップを分割・誘導することで、複雑な脆弱性をより迅速に発見することを可能にしています。

## 重要ポイント

- GitHub Security Lab Taskflow Agentを活用し、Androidアプリケーションの脆弱性監査を自動化して24件の脆弱性を発見した。
- カスタムタスクフローのプロンプトを用いることで、LLMを誘導して複雑な脆弱性を効率的に検出できる。
- オープンソースとして公開されているタスクフローは、GitHub Copilotライセンスを利用して自身のプロジェクトで実行可能である。
