> [!abstract] AI要約
> オープンソースのGitプロジェクトより、Git 2.56がリリースされた。本バージョンには104人以上のコントリビューターによる機能追加やバグ修正が含まれている。主要な新機能として、競合解決のワークフローを安全に行うための「git add --resolved」オプションが導入された。この新機能では、未解決の競合マーカーが残っているファイルを検出するとエラーを表示し、関係のない変更を誤ってステージングするリスクを防ぎつつ、競合が解決されたファイルのみを安全にステージングすることができる。また、バイナリの競合や削除されたファイルにも対応しており、開発者がマージ作業を行う際の安全性が高められている。

## 重要ポイント

- Git 2.56がリリースされ、104人以上のコントリビューターによる変更が統合されました。
- 新機能「git add --resolved」により、競合が解決されたパスのみを安全にステージングできるようになりました。
- 競合マーカーが残っているファイルがある場合、Gitはステージングを阻止し、意図しない変更の混入を防ぎます。
