> オープンソースの分散バージョン管理システムGitのバージョン2.56がリリースされ、104名以上のコントリビューターによる機能追加やバグ修正が行われました。今回のリリースにおける注目すべき新機能の一つが、マージ競合の解決プロセスを安全に行うための「git add --resolved」オプションです。これまでのgit add -uなどでは意図しないファイルや競合マーカーが残ったファイルまでステージングされてしまうリスクがありましたが、新しい--resolvedモードでは、未解決の競合マーカーが含まれていないかを自動スキャンした上で、競合が解消されたパスのみを安全にステージングします。これにより、未関係のローカル変更がある状態でも安全なマージ作業が可能となり、開発者のワークフローにおける安全性が向上しています。

## 重要ポイント

- Git 2.56がリリースされ、104名以上のコントリビューターによる改善が含まれています。
- 新機能「git add --resolved」により、競合が正しく解決されたファイルのみを安全にステージングできるようになりました。
- 未解決の競合マーカーが残っているファイルを検出した場合、Gitはインデックスを変更せずエラーを報告します。
