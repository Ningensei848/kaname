# コードとしてのマーケティングOps：GitHubでのイベント企画からフォローアップまでの自動化

> [!abstract] AI要約
> GitHubの日本および韓国におけるマーケティング担当者であるTomoko Tanaka氏が、GitHub Copilotを活用してイベント運用の全工程を自動化した事例について紹介しています。従来、イベントの承認後に発生するランディングページの複製、UTMタグ付きリンクの生成、メール案の作成、プロジェクトボードへの追加、参加者リストの集計とステータス更新、終了後のCRM用データ整形やレポート作成といった一連の定型作業は、ヒューマンエラーのリスクを伴う負担の大きいものでした。元エンジニアである著者は、自身の手順書をGitHub Copilotに渡し、対話を重ねることでコードを生成させました。その結果、1つのGitHub Issueからイベントの自動セットアップ、毎朝の登録者スクリーニング、終了後の後片付けまでが自動で行われる「Marketing ops as code」の仕組みが実現されました。イベント管理の基本単位としてGitHub Issueを用い、issue formを構造化された申請フォームとして活用しています。

## 重要ポイント

- イベント運用の定型作業（ランディングページ作成、UTMリンク生成、メール作成、集計など）を自動化
- GitHub Copilotとの対話を通じて、コードを書かずに手順書ベースで自動化パイプラインを構築
- GitHub Issueをイベントの基本単位として採用し、issue formにより構造化された入力インターフェースを実現
