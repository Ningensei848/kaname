# GitHub Copilotアプリ入門：diff、ターミナル、ブラウザの活用法

> [!abstract] AI要約
> GitHub Copilotアプリを使用することで、エージェントが生成したコードの変更確認、コマンドの実行、Webアプリのプレビューをタブを切り替えることなく1箇所で行えるようになりました。diffパネルでは追加や削除されたコード行を視覚的に比較して承認や修正指示が出せます。ターミナルパネルではプロジェクトのスクリプトを実行して開発サーバーを起動でき、複数のターミナルウィンドウの切り替えも可能です。ブラウザパネルでは「Pick & Polish」ツールを用いてUI要素を選択し、エージェントと対話しながら修正を続けられます。これらを組み合わせることで、AIコードのレビューからプルリクエスト作成までの開発ループをシームレスに完結させられます。

## 重要ポイント

- diffパネルにより、AIエージェントによるコードの変更点を視覚的に確認し、承認や追加の修正依頼が可能
- ターミナルパネルを利用して、アプリ内から直接スクリプトや開発サーバーのコマンドを実行可能
- ブラウザパネルと「Pick & Polish」ツールを使用し、UIのプレビューや要素の調整を同一環境内で実施できる
- 一連のレビュー、実行、ブラウザ確認、イテレーションのサイクルを1つのアプリ内で完結し、プルリクエスト作成まで行える
