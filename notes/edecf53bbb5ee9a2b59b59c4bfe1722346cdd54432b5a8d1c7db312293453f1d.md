# 連合学習（Federated Learning）におけるプライバシー保護の強化：信頼できる実行環境（TEE）の活用

> [!abstract] AI要約
> Google Researchは、分散型データのプライバシー保護をさらに強化する次世代の連合学習（FL）システムを発表した。新システムは、信頼できる実行環境（TEE）を活用することで、サーバー事業者を完全に信頼する必要のない、検証・監査可能なデータ匿名化の保証を提供する。システムは「データアップロード」「KMSとポリシー検証」「ワークロード実行」「フォールトトレラント復旧」の4つの核心概念で構成されており、アクセスポリシーを公開透明性ログに登録することで第三者による検証を可能にしている。[[Gboard]]ではすでにこの新システムが導入され、従来システムに比べてより強力なプライバシー保証と精度の向上、および大幅な学習時間の短縮を実現している。

## 重要ポイント

- 信頼できる実行環境（TEE）を利用して、検証および監査が可能なデータ匿名化の保証を実現。

![A technical architecture diagram illustrating a confidential federated learning system with secure data flow and verification steps.](<https://storage.googleapis.com/gweb-research2023-media/images/ProvablyPrivateLearning2-Data_Overview.width-1250.png>)
- アクセスポリシーを公開透明性ログに登録し、外部の監査人がサーバー側のワークロードを追跡可能。
- サーバー側での並列計算や動的なデバイス参加スケジュールの最適化により、[[Gboard]]におけるモデル学習速度が大幅に向上。

![A line graph comparing privacy-utility curves between a previous federated learning system and a new TEE-based system.](<https://storage.googleapis.com/gweb-research2023-media/images/ProvablyPrivateLearning2-Data_Curves.width-1250.png>)
