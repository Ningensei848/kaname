# 次の開発者インターフェースはアンビエントインテリジェンスである

> [!abstract] AI要約
> GitHub Blogに掲載されたMartin Woodwardによる記事で、AI、エージェント、音声、物理的なコントロールによってソフトウェア開発がツール操作から意図の表現へと移行している現状を解説しています。従来のキーボード、マウス、エディタを中心とした開発関係から、AIがリポジトリの文脈を理解し、計画、ツールの利用、ファイル編集、テスト実行を自律的に行うループへの変化が述べられています。[[GitHub Copilot]]の[[エージェントモード]]やバックグラウンドでの[[GitHub Actions]]を活用したプルリクエスト作成は、単なる高速コーディングではなく、開発者が指示の出し手から結果の方向付けや制約の定義、検証を行う役割へのシフトを示しています。[[アンビエントインテリジェンス]]としてのAIをワークフローに組み込むためには、MCPなどのポータブルなコンテキストや、モダリティ、ハーネス、コントロールプレーンという3つのレイヤーが重要であり、開発者が制御を手放さずに生産性を高める仕組みが解説されています。

## 重要ポイント

- AIの進化により、開発者はツールの手動操作から意図の表現や方向付けへとシフトしている。
- [[GitHub Copilot]]のエージェント機能は、リポジトリのコンテキストを把握してファイル編集やテスト実行、プルリクエスト作成までを自律的に行える。
- 開発作業の中心がコードの記述から、アーキテクチャの妥当性、移行の安全性、テストの有効性といった判断や味覚（テイスト）の評価へと移行している。
- 今後のワークフローはAIを隣に置くのではなく[[アンビエントインテリジェンス]]として埋め込み、モダリティ、ハーネス、コントロールプレーンの3層で構築される。
