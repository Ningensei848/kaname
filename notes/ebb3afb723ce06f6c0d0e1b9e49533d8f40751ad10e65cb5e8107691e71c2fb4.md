# CARE-X: 補助的監督、報酬アライメント学習、ツール拡張型計測を備えた臨床的に有用な放射線科向けVLMの実現

> [!abstract] AI要約
> CARE-Xは、胸部X線画像の解釈タスクに向けて開発された統合型の放射線科向け[[視覚言語モデル]]（VLM）です。SigLIP2視覚エンコーダーとPhi-4-mini-instruct言語モデルを基盤とし、自由記述のレポート生成と構造化された補助ヘッドによる分類・視覚的グラウンディングを同時に実現しています。標準的な交差エントロピー損失の課題を克服するため、臨床報告、診断精度、空間的グラウンディング品質に対するタスク特異的報酬を用いた[[DAPO]]ベースの強化学習を採用しています。さらに、Qwen3-VL-4B-Instructに決定論的計測ツールを組み合わせたツール拡張型計測の検証実験では、[[心胸郭比]]や大動脈の拡張などの定量的な測定が必要な条件において、視覚的近似のみの手法と比較して大幅な性能向上が確認されました。インドのNarayana Healthの臨床データやCT確認済みの検証でも高い一般化性能を示しており、放射線科AIの臨床的有用性を高めるアプローチとして注目されています。

An orchestrator routes a user’s image query to a VLM, which performs image analysis, calls measurement tools to calculate cardiac and thoracic widths and the cardiothoracic ratio \(CTR\), and returns diagnostic metrics with vi](<https://www.microsoft.com/en-us/research/wp-content/uploads/2026/08/CAREX-BlogHeroFeature-1400x788-1-scaled.jpg>)

## 重要ポイント

- CARE-Xは、自由記述の生成と分類・グラウンディングを行う補助ヘッドを統合し、単一モデルで多様な臨床解釈タスクに対応する。

![CARE-X architecture with a SigLIP2 vision encoder, Phi-4-mini backbone, classification and grounding auxiliary heads, language modeling, and DAPO alignment for report generation, VQA, and grounding.](<https://www.microsoft.com/en-us/research/wp-content/uploads/2026/08/Figure_1_CARE-X_updated.png>)
- タスク特異的報酬を用いた[[DAPO]]強化学習により、臨床的な正確性や空間的精度を最適化している。

![CRIMSON scores \(↑\) for CARE-X against baseline report-generation models across four chest X-ray datasets — ReXGradient, MIMIC-CXR, IU-Xray, and CheXpert-Plus. CARE-X \(highlighted\) achieves the highest CRIMSON score on every dataset.](<https://www.microsoft.com/en-us/research/wp-content/uploads/2026/08/FIG2_CARE_NOLOGO.png>)
- Qwen3-VL-4Bと決定論的計測ツールを組み合わせた推論により、定量的な測定が必要な異常の検出精度が大幅に向上する。

![Diagram illustrating a workflow for a medical assistant using a vision-language model \(VLM\) to analyze chest X-ray images and provide diagnostic metrics. Key components include orchestrator handling prompts and tool calls, assistant performing perception and tool calls to measure cardiac and thoraci](<https://www.microsoft.com/en-us/research/wp-content/uploads/2026/08/Figure_4_CARE-X_updated.png>)
