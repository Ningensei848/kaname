# Microsoft Researchが発表した汎用zkVM「Magnetar」：標準ハッシュ関数に基づく高速なゼロ知識証明

> [!abstract] AI要約
> Microsoft Researchは、プログラムの実行結果が正しく生成されたことを証明する新しいゼロ知識仮想マシン（zkVM）「[[Magnetar]]」を発表しました。[[ゼロ知識証明]]の普及を阻んできた「効率性」「汎用性と使いやすさ」「セキュリティ」という3つの課題に対し、[[Magnetar]]は大きな進歩をもたらしています。RustやGo、Cなどの一般的な言語で書かれた[[RISC-V]]プログラムをそのまま証明対象とし、ラップトップ上で1秒間に720万〜870万命令を証明可能です。従来の同等システムと比較して平均で10〜39倍高速であり、証明の検証は約12ミリ秒で行われます。さらに、楕円曲線や格子暗号、信頼できるセットアップ（Trusted Setup）に依存せず、インターネットの保護に使われてきた[[SHA-256]]やSHA-3などの標準的なハッシュ関数のみにセキュリティの基盤を置いているため、量子コンピュータに対しても安全です。十年にわたる研究の成果を結集した[[Magnetar]]により、開発者は特別な暗号の専門知識なしで、日常的なコードの実行結果を信頼に頼らず検証できるようになります。

![Figure 1. Magnetar proves a program's execution and returns a small proof that anyone can check, with security resting only on standard hash functions.](<https://www.microsoft.com/en-us/research/wp-content/uploads/2026/10/Magnetar_NEW_Summary_Simple.png>)

## 重要ポイント

- [[Magnetar]]は、RustやGo、C言語で書かれた[[RISC-V]]プログラムの実行をそのまま証明できる汎用的なzkVMである。
- ラップトップ上で1秒間に720万〜870万命令を証明し、同等クラスの既存システムと比較して平均10〜39倍高速に動作する。
- 楕円曲線や新しい暗号関数を使わず、[[SHA-256]]などの標準的なハッシュ関数のみにセキュリティを依存しているため耐量子安全性を持つ。
- 証明の検証が約12ミリ秒と非常に高速であり、大規模な計算やブロックチェーンなどの長期間稼働するシステムにも適用できる。
