# 実践の未来：生成UIを活用して教師がインタラクティブな学習教材を作成できるようにする

> [!abstract] AI要約
> Google Researchは、教育現場におけるアクティブ・ラーニングを支援するため、生成UI（GenUI）を最適化し、教師がカリキュラムや学習目標に合わせてカスタム可能な教育用シミュレーションを作成できる新しい研究実験を発表しました。この仕組みでは、教師が目標を設定した上で、構造化されたゲームレベルやAI生成の足場かけ（ヒントやフィードバックなど）を持つ教材を動的に生成します。品質管理のために、自動評価やソルバビリティ評価、教師による厳格な検証を含む自己修正ループが組み込まれており、物理、化学、生物、数学などのSTEM分野におけるサンプルライブラリが公開されています。初期の教師による評価では、指導目標との一致度や段階的な難易度設定について高い評価を得ており、今後はGoogle for Educationのパイロットプログラムを通じてさらなる検証と展開が進められます。

![A screenshot of an interactive learning module library interface, showing a sidebar with subjects and a main grid displaying eight vetted educational activity cards.](<https://storage.googleapis.com/gweb-research2023-media/images/LearningInteractives4_Library.width-1250.png>)

## 重要ポイント

- 生成UI（GenUI）を活用し、教師がカリキュラムや学習目標に合わせたインタラクティブな学習教材を動的に作成できる研究が発表された。
- ゲームベースの学習デザインを取り入れ、段階的な難易度やヒント、フィードバックなどのAI生成による足場かけが組み込まれている。

![An annotated screenshot of an educational interactive web interface titled "Symmetrical Opposites," demonstrating number line positions with red and blue rovers, alongside labeled UI features such as guidance, feedback, and tools.](<https://storage.googleapis.com/gweb-research2023-media/images/LearningInteractives1_Interface.width-1250.png>)
- 自動評価や自己修正ループ、教師による検証プロセスを組み合わせることで、教育的な品質や事実の正確性を担保している。

![A workflow diagram illustrating the step-by-step creation, automated evaluation, and manual teacher validation process for educational interactives.](<https://storage.googleapis.com/gweb-research2023-media/images/LearningInteractives2_Validation.width-1250.png>)
- 物理、化学、生物、数学などのSTEM分野を対象とした30件以上のサンプルライブラリが公開されており、教師からの評価も高い。

![A clustered bar chart comparing teacher evaluation ratings \(from Fail to Excellent\) across ten pedagogical and design criteria for four subjects and an overall average.](<https://storage.googleapis.com/gweb-research2023-media/images/LearningInteractives3_Ratings.width-1250.png>)

## 資料の位置づけ

本資料は、Google Researchによる教育向け生成AIおよび生成UIの最新の取り組みを紹介する技術・研究レポートです。静的な教材にとどまっていた従来のデジタル学習に対し、AIを活用して動的かつインタラクティブな演習環境を構築するアプローチや、品質担保のための自動検証ループと教師によるレビューの仕組みについて詳しく解説されており、教育テクノロジーや生成AIの応用に関心を持つ研究者や教育関係者にとって参照価値の高い内容となっています。
