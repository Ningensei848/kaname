# kaname generated Notes

LLMが生成した技術記事の要約です。正確性は出典で確認してください。
記事原文・運用台帳・人力Vaultは含みません。元記事の権利は各権利者に帰属します。

manifest.jsonのNote ID・SHA-256・dataset digestで同じ版を照合できます。
Git submoduleではcommitを固定して参照し、更新は利用側で明示してください。
生成領域の変更を強制reset/cleanせず、人の注釈は領域外に保持してください。

旧形式の打切りNoteは、上限文字数と本文の注意表示が保存されていない場合があります。
`llm_input_truncated: true`を確認し、記事全体は原典で確認してください。
Web版はこの場合に上限値未記録の注意を表示します。元Noteのbytesは変更しません。
